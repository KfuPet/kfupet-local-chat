# KfuPet-local-chat

> ⚠️ Important: This is **NOT the KfuPet desktop pet main project** .
> 
> 本プロジェクトは**KfuPetのデスクトップペット本体ではない**。独立したローカルAIチャットコアです。

## 📖 プロジェクト紹介
本プロジェクトは、基本的な会話機能を実現するシンプルなローカル大規模モデルチャットシステムです。

すべてがローカルで動作し、クラウド上のAIインターフェースに依存しません。

これはKfuPetのデスクトップペットがローカルモデルに接続するために使用する下位レベルの参考基盤です。

開発者の方々が学習・参考として活用できます。

## 📌 説明
このリポジトリは主にローカル大規模モデルの接続ソリューションを学ぶためのものであり、コードは軽量設計されており、他のプロジェクトへの移植も容易です。
