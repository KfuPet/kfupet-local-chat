# KfuPet-local-chat

> ⚠️ Important: This is **NOT the KfuPet desktop pet main project** .
>
> This project is **not the main body of KfuPet tabletop pet**, but rather a standalone local AI chat core.

## 📖 Project Introduction
This project is a minimalist local large model chat implementation, demonstrating only basic conversation capabilities.

All runs locally and does not rely on any cloud AI interfaces.

It serves as the underlying reference base for KfuPet tabletop pets to connect to local models.

The project is available for developers to reference and learn from.

## 📌 Notes
This repository is mainly used for learning and referencing local large model integration solutions. The code is lightweight and convenient for porting to other projects.
