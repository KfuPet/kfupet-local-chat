# kfupet-local-chat

> ⚠️ Important: This is **NOT the KfuPet desktop pet main project** .
> 
> 本项目**不是 KfuPet 桌宠本体**，是配套独立的本地AI聊天核心。

## 📖 项目介绍
本项目是一个极简本地大模型聊天实现，只演示基础对话能力。

全部在本地运行，不依赖任何云端AI接口。

它是 KfuPet 桌宠用来接入本地模型的底层参考底座。

项目可供广大开发者参考学习

## 📌 说明
本仓库主要用于学习、参考本地大模型接入方案，代码偏向轻量化，方便移植到其他项目。
